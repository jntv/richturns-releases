# RichTurns for Android

Official Android APK downloads for RichTurns. This repository contains download metadata and release binaries, not the game source.

Download the current APK from [Releases](https://github.com/jntv/richturns-releases/releases). Android asks before installing an update. The app can notify you when a newer version is available; installation stays under your control.

Up to three published versions are retained. Older links may stop working after a later release.
